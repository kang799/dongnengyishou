目标：让新手基础教程必须按步骤完成，误点聚光灯外不会跳过；同时修复游客退出后再次选择“继续游客”仍登录失败的问题。

实施计划：

1. 强制新手聚光灯教程
- 修改 `SpotlightTour.tsx`：移除遮罩区域点击即 `endTour` 的行为，聚光灯外点击不再关闭引导。
- 只允许用户通过当前步骤要求的操作前进：
  - 普通介绍步骤：点击「下一步」。
  - 操作步骤：必须点击高亮目标元素（例如“前往修行”“启动修行”）。
- 保留一个明确但不误触的「跳过」入口；如果要完全强制不可跳过，可将跳过按钮也隐藏到非新手流程中。
- 修复当前教程第 3 步 selector 指向错误：`tour-steps.ts` 里使用了 `[data-tour='nav-train']`，但现有页面实际给的是宠物页按钮 `[data-tour='pet-go-train']`，会导致目标找不到。改为指向宠物页“前往修行”按钮，让用户按流程进入修行。

2. 修复游客恢复登录失败
- 当前失败原因很可能是退出时调用了全局 `signOut()`，这会让后台会话失效；之后本地保存的游客 access/refresh token 无法再 `setSession()`，所以只能新开游客。
- 修改退出逻辑：如果当前用户是游客，则使用本地范围退出或只清除当前浏览器会话，避免注销掉后台保存的游客 refresh token；这样下次进入登录页可以用本地缓存恢复。
- 为 `guest-session.ts` 增加更稳的游客缓存更新/校验：保存游客 token、用户 id、时间；恢复失败时提示“身份已失效”并清理缓存。
- 在登录页 `auth.tsx` 恢复游客后，如果拿到新 session，立即刷新保存新的 access/refresh token，避免 token 轮换后下次又失效。

3. 验证
- 检查游客流程：游客登录 → 退出 → 进入登录页 → 弹出双选项 → 选择继续游客 → 回到原游客账号数据。
- 检查新手流程：欢迎页结束后进入聚光灯；点遮罩不会关闭；只能按步骤点下一步或高亮目标继续。
