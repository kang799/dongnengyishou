### 一、使用说明书
- **适用场景**：解决"健身难坚持"的问题——把深蹲/俯卧撑/仰卧起坐转化为喂养山海经异兽的"真气"，用养成+排行+对战的玩法激励锻炼；面向想边玩边健身的用户。
- **快速开始**：访问网址 → 游客入山或邮箱注册（需邮箱验证）→ 结契异兽 → 新手引导（欢迎卷轴 + 聚光灯分步）→ 前往修行开启摄像头完成首次深蹲。
- **功能说明**：三式修行（摄像头自动计数：深蹲炼速/俯卧撑炼力/仰卧起坐炼体）、异兽养成（三维属性、六阶进化、自由属性点批量加点）、封神三榜（属性榜/战力榜挑战换位制/打卡榜）、斗兽台回合制切磋（速度影响闪避命中）、道友录（加好友、申请、私聊传音）、头像上传。
- **常见问题**：摄像头权限、游客账号恢复与覆盖、邮箱验证、断签清零、战斗不加属性等。

### 二、技术实现说明书
- **整体架构**：TanStack Start v1（React 19 + SSR/文件路由）+ Vite 7 + Tailwind v4；后端 Lovable Cloud（Supabase：Postgres + RLS + Auth + Realtime + Storage）；部署于 Cloudflare Workers；附核心流程图（文字/ASCII：动作识别 → 属性入库 → 进化/榜单/对战）。
- **关键实现**：
  - 姿态计数：MediaPipe PoseLandmarker（WASM，浏览器端推理），关节角度+校准基线判定动作相位，模块级模型缓存。
  - 战斗模拟：种子随机数回合制，速度定先手与闪避率（差距过大必闪必中），力量/体质只加攻血；战斗不改属性，仅挑战高位胜者换位。
  - 数据与权限：RLS 策略、GRANT、安全 definer 函数；游客匿名登录 + 本地 refresh_token 恢复/覆盖删除（service role server function）。
  - 新手引导：onboarded_at 服务端标记 + 事件驱动聚光灯（文档坐标定位）。
  - 水墨朋克 UI：宣纸纹理、朱砂强调色、墨晕动效。
- **使用的 AI 工具**：Lovable AI 辅助全栈代码生成与迭代调试、AI 图像生成（异兽 logo/水墨素材）、AI 文档撰写。
