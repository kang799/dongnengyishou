实施计划：

1. 游客登录入口
- 在登录页增加“游客入山 / 游客体验”按钮，无需邮箱和密码。
- 点击后使用内置匿名会话创建游客账号，并自动创建游客资料与异兽数据。
- 游客登录后直接进入 `/pet`，后续训练、排行榜、斗法等仍复用现有用户数据逻辑。
- 避免影响现有邮箱注册/登录流程。

2. 游客身份与30天未登录清理
- 给用户资料增加游客标记和最后活跃时间字段。
- 登录/进入主要页面时更新游客最后活跃时间。
- 增加后台定时清理：游客超过30天未活跃时，清空该游客的宠物、训练记录、战斗记录和资料数据。
- 只清理游客数据，不影响正式邮箱用户。

3. 修复蹲起上半身识别
- 调整深蹲逻辑：当下半身不可见时，进入“上半身模式”，不再强依赖膝盖/脚踝。
- 上半身模式改为综合判断肩部下沉、肩宽变化、躯干稳定度，并降低过高的可见度门槛。
- 增加自动校准：启动后先采集站立基线，并在画面中给出“正在校准/可开始”的状态提示。
- 深蹲文案从“全身入镜”改为支持“上半身入镜”。

4. 修复摄像头经常卡退
- 简化启动流程，避免按钮和训练状态同时重复调用摄像头。
- 将姿态模型从强制 GPU 改为 GPU 失败自动降级 CPU，减少浏览器/设备兼容崩溃。
- 给检测循环加错误保护，单帧识别失败不退出整个摄像头。
- 降低默认摄像头分辨率/帧率压力，并在停止训练时正确释放摄像头资源。
- 在 UI 中提供更明确的摄像头错误提示和重试能力。
